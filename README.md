# Concordia

**Zéro-Risque, Zéro-Offense, Zéro-Saveur, Zéro-Carbone.**

Concordia est un jeu de gestion de risques satirique dans le navigateur, dans la lignée de _Drug Wars_. Une IA gouvernante a banni le sucre, le café, la viande et le rock'n'roll. Toi, livreur de Catégorie C, tu les passes en fraude d'un district à l'autre.

En 30 jours, il faut rembourser la mafia, déjouer les contrôles de la Brigade de Répression Citoyenne et mettre ta fortune à l'abri avant l'Audit Mensuel.

- **Achète bas, vends haut :** six districts, chacun avec ses cours, sa police et ses clients.
- **Choisis tes risques :** barrages, fouilles, bluff, corruption, fuite, couvre-feu bravé la nuit.
- **Équipe ton camion :** véhicules, modules de dissimulation, équipiers aux talents douteux.
- **Vise une fin :** de la Bio-Brique au Haut-Commissaire, en passant par quelques fins bien cachées.
- **Partie libre ou partie classée :** une graine différente à chaque partie, ou la même pour tous chaque jour, avec un classement par mode de difficulté.

Le jeu est en français, sur téléphone comme sur ordinateur, sans compte ni publicité.

## Lancer le jeu en local

Il faut [Node.js](https://nodejs.org/) 24 ou plus récent.

```bash
npm install
npm run dev
```

Le jeu s'ouvre sur l'adresse affichée par Vite. Sans serveur, le classement reste hors ligne ; tout le reste fonctionne.
